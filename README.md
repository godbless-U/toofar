# مدار | MADAR — مدیریت کارها و اهداف با صدای فارسی

**یک پروژه واقعی Android، با سورس Java و SQLite، مناسب انتقال مستقیم به GitHub و خروجی APK از GitHub Actions.**

> ⚠️ وضعیت بیلد: ساختار Gradle/manifest و نسخه وابستگی‌ها با منابع رسمی بررسی شده و تست مستقلِ پردازش متن اجرا شده است، اما در محیط تولید فایل، Android SDK و دسترسی شبکه به Maven وجود ندارد؛ بنابراین امکان اجرای `assembleDebug` و تست واقعی APK اینجا فراهم نبود. ادعای «بیلد صددرصد تست‌شده» نمی‌کنیم. GitHub Actions پس از Push وضعیت واقعی بیلد را نشان می‌دهد.

## قابلیت‌های پیاده‌سازی‌شده

- صفحه اصلی با دسترسی برجسته به میکروفون، تم فضایی ساخته‌شده با Canvas و کارت‌های نیمه‌شفاف با گرادیان.
- تشخیص گفتار **واقعی** فارسی با Vosk به صورت **روی دستگاه** (۱۶ کیلوهرتز، شناخت پیوسته و نتایج جزئی).
- دانلود و نصب مدل رسمی `vosk-model-small-fa-0.42` فقط یک‌بار، از سرور سازنده. حجم مدل فشرده حدود ۵۳MB است؛ پس از نصب، گفتار بدون اینترنت تبدیل می‌شود.
- نمایش گفتار خام و پیشنهاد نسخه رسمی‌تر با قواعد محلی؛ **این بخش LLM نیست و جای بازخوانی انسانی را نمی‌گیرد**.
- اولویت «صدا» در ثبت، دکمه ضبط بزرگ و ضربان‌دار، هشدار اطمینان پایین واژه‌ها و امکان تایپ دستی، اصلاح، پاک کردن و رسمی‌سازی مجدد متن.
- انتخاب یک لیست موجود پس از تشخیص صدا؛ یا ساخت لیست جدید و افزودن وظیفه/وظایف. برای جداکردن چند وظیفه می‌توان «کار بعدی» یا «مورد بعدی» گفت.
- ذخیره همه اطلاعات در SQLite محلی، بدون اکانت، بدون Analytics و بدون ارسال متن/صوت به سرور.
- ساخت، ویرایش، حذف لیست‌ها؛ انتخاب چندگانه با لمس طولانی؛ حذف گروهی و بکاپ منتخب.
- ساخت، ویرایش، حذف و انجام وظایف با توضیح، سطح اهمیت، موعد اختیاری و تکرار روزانه/هفتگی/ماهانه/سالانه؛ پس از تکمیل وظیفه تکرارشونده، مورد بعدی ایجاد می‌شود.
- افزودن چند مرحله به هر وظیفه؛ هر مرحله چک‌باکس مستقل، موعد اختیاری، ویرایش/حذف، انیمیشن تکمیل و اعلان یک دقیقه پیش از موعد دارد.
- اعلان موعد با دو اقدام: «انجام شد» (ثبت مستقیم) و «هنوز نه؛ ۱۰ دقیقه بعد» (پیگیری مجدد).
- پیگیری روزانه در ساعت‌های ۹:۰۰، ۱۲:۰۰، ۱۵:۰۰، ۱۸:۰۰ و ۲۱:۰۰؛ در صورت نبود کار ثبت‌شده، پیام تشویقی برای ساخت هدف/لیست ارسال می‌شود. این قابلیت از تنظیمات قابل خاموش/روشن کردن است و به‌صورت پیش‌فرض روشن است.
- جستجوی متن وظایف در همه لیست‌ها.
- یادآوری‌ها به‌صورت محلی با AlarmManager زمان‌بندی می‌شوند؛ برای بیشترین دقت در Android 12+، کاربر باید دسترسی «اعلان‌های دقیق» را در تنظیمات فعال کند. محدودیت باتری گوشی ممکن است زمان اعلان را تغییر دهد.
- پیشرفت هر لیست و پیشرفت کلی؛ دکمه بزرگ جشن موفقیت پس از تکمیل **تمام** کارهای لیست، با پنجره، ویبره و نوتیفیکیشن.
- اهداف شخصی: روزانه / هفتگی / ماهانه / سالانه، تفکیک بازه‌های زمانی و مرور بازه‌های پیشین و بعدی.
- برنامه محل کار: روزانه / ماهانه / سالانه / هدف نهایی، با ثبت و علامت‌گذاری تکمیل.
- بکاپ نسخه‌دار `.json` از همه داده‌ها (لیست‌ها، کارها، مراحل، موعدها و اهداف) یا فقط لیست‌های انتخابی و همه کارها و مراحل درونشان؛ واردکردن بکاپ نسخه ۱ و ۲ پشتیبانی می‌شود.
- ورود فایل بکاپ با Storage Access Framework، بررسی اعتبار قالب و بازیابی تراکنشی، بدون ایجاد رونوشت از رکوردهای هم‌شناسه.

## ساخت APK با GitHub (بدون نصب Android Studio روی کامپیوتر)

1. محتوای این ZIP را به **ریشه** یک مخزن جدید GitHub انتقال دهید (پوشه `.github` را مخفی نکنید).
2. به تب `Actions` بروید و Workflow با عنوان `Build MADAR Android APK` را فعال کنید.
3. `Run workflow` را بزنید، یا یک Commit/Push تازه انجام دهید.
4. پس از سبزشدن Workflow، در `Artifacts` فایل `MADAR-debug-apk` را دریافت کنید.
5. داخل Artifact، فایل `app-debug.apk` است. آن را روی دستگاه اندرویدی نصب کنید.

فایل `.github/workflows/android.yml` به‌صورت خودکار JDK 17، Gradle 8.13 و Android SDK 36 را نصب می‌کند. در اصلاحیه بیلد، `android-actions/setup-android@v4.0.4` استفاده شده و بسته منسوخ `tools` صریحاً درخواست نمی‌شود؛ بسته‌های لازم (`platform-tools`، `platforms;android-36` و `build-tools;36.0.0`) مستقیم نصب و سپس وجودشان بررسی می‌شود. جزئیات علت خطا در `BUILD_FIX.md` آمده است. دستور بیلد و تست:

```bash
gradle --no-daemon :app:assembleDebug :app:testDebugUnitTest
```

نسخه‌ها: `AGP 8.13.2`، `Gradle 8.13`، `Java 17`، `Android SDK Platform 36`، `Build Tools 36.0.0`، `compileSdk 36`، `targetSdk 35`، `minSdk 26`، `Vosk 0.3.75` و `JNA 5.18.1`. نسخه فعلی برنامه `1.1.0` است.

این ZIP **سورس است نه APK از پیش بیلدشده**. برای بیلد محلی (Linux/macOS)، `./gradlew :app:assembleDebug` را اجرا کنید؛ Gradle در صورت عدم نصب از توزیع رسمی دریافت می‌شود. در ویندوز `gradlew.bat` نیز Gradle را در صورت نیاز از وب‌سایت رسمی دریافت می‌کند (Android SDK باید نصب باشد).

## تست گفتار به صورت دقیق

موتور Vosk یک تشخیص‌گر واقعی و متن‌باز است، اما **هیچ تضمینی برای درک کامل فارسی محاوره‌ای** یا تبدیل معنایی حرفه‌ای به فارسی رسمی وجود ندارد. نرخ خطای واژه (WER) گزارش‌شده سازنده برای مدل کوچک فارسی: ۲۳٫۴٪ روی Common Voice 17 و ۱۴٪ روی FLEURS است؛ این معیارها برای گفتار خاص هر شخص قابل تعمیم قطعی نیستند.

برای سنجش کیفیت، با حداقل ۵۰ فایل صوتی از چند گوینده (محاوره‌ای، اصطلاحات کاری، محیط ساکت و شلوغ) متن مرجع تهیه کنید، خروجی `raw` را با مرجع مقایسه و WER را محاسبه کنید. فرایند در `VOICE_TEST_PLAN.md` آمده است. تست‌های پذیرش موعدها، مراحل، اعلان‌های روزانه و بکاپ در `REMINDER_TEST_PLAN.md` آمده‌اند. برای ارتقای چشمگیر رسمی‌سازی و دقت تشخیص صدا، باید بعدها مدل‌های Whisper / یک LLM فارسی را با مدیریت مصرف RAM/باتری/حجم مدل به اپ افزود؛ **این نسخه ادعا نمی‌کند که Whisper یا LLM را پیاده کرده است.**

## اطلاعات امنیتی

- فقط برای دانلود مدل گفتار، مجوز INTERNET وجود دارد. صوت ضبط‌شده ارسال نمی‌شود.
- هر بکاپ JSON **متن ساده و رمزگذاری‌نشده** است. فایل را در مکان امن نگه دارید.
- مجوز ضبط صدا هنگام شروع ضبط درخواست می‌شود.
- اعلان‌ها در نسخه‌های جدید اندروید به مجوز نیاز دارند؛ اگر اجازه ندهید پنجره موفقیت همچنان نمایش داده می‌شود. برای زمان‌بندی دقیق، دسترسی Alarm & reminders نیز ممکن است لازم باشد.
- بکاپ خودکار اندروید غیرفعال است؛ از گزینه خروجی JSON برای مهاجرت دستگاه استفاده کنید.
- اگر فایل بکاپ با نسخه دیگر/ساختار نامعتبر وارد شود، داده‌ها پاک یا بازنویسی نمی‌شوند.

## محدودیت‌های فعلی

- اجرای دقیق ِبیلد و رابط روی گوشی اندروید در این محیط امکان‌پذیر نبود؛ باید نتیجه GitHub Actions و تست میکروفون روی دستگاه بررسی شود.
- همه امکانات Todoist، Tasks.org یا Vikunja در این نسخه نیستند: همگام‌سازی چند دستگاه، همکاری تیمی، ضمیمه، تقویم هجری شمسی، زیروظیفه‌های تودرتوی چندسطحی، ویجت و مدل مولد فارسی هنوز پیاده نشده‌اند. مرحله‌های هر وظیفه در این نسخه یک سطحی هستند.
- مدل کوچک، دسترسی به منابع کمتر را بر کیفیت حداکثری اولویت می‌دهد؛ برای تشخیص بسیار دقیق محاوره باید ارزیابی عملی و احتمالاً تعویض موتور انجام داد.
- Gradle bootstrap ویندوز نیازمند Gradle نصب‌شده است. در GitHub Actions نصب مستقل انجام می‌شود.

## ساختار پوشه‌ها

```text
app/src/main/java/ir/madar/app/
  MainActivity.java        # UI و جریان کاربر
  Store.java               # پایگاه داده، وظایف، اهداف، بکاپ و import
  ModelManager.java        # دانلود امن و بارگذاری مدل Vosk
  PersianFormatter.java    # تبدیل واژگانی گفتار غیررسمی به رسمی‌تر
  ReminderReceiver.java    # اعلان موعد، پیگیری روزانه و جشن موفقیت
  BootReceiver.java        # برنامه‌ریزی دوباره اعلان‌ها بعد از روشن شدن گوشی
.github/workflows/android.yml   # Build + Unit test + APK artifact
app/src/test/.../PersianFormatterTest.java
```
